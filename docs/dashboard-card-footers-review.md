# Хяналтын самбарын тайлбар, төлбөрийн үлдэгдэл — local тайлан

Огноо: 2026-10-14. Суурь production commit: `9bc8bee8d51e479b7a00b2fe30440934cba66358`.

## Өөрчлөлт

- Төхөөрөмж тавиагүй: доод тайлбар «Программ уншуулсан».
- Программ суулгаагүй: доод тайлбар «Төхөөрөмж тавиулсан».
- Аль нэг ажил дутуу: «Программ эсвэл төхөөрөмжийн ажил дутуу» хэвээр.
- Урьдчилгаа төлөөгүй: үндсэн тоо нь нийт төлсөн дүн 0 байх одоогийн нөхцөлөөр хэвээр. Доор нь «Төлбөрийн үлдэгдэлтэй: N машин», «Нийт үлдэгдэл: X₮» гэсэн хоёр мөр нэмсэн.

Санхүүгийн мэдээлэл API-ийн одоо байгаа outstandingCount, outstandingBalance утгуудаас үүснэ. Тоо, мөнгөн дүнг hardcode хийгээгүй. Монгол төгрөгийн мянгатын тусгаарлагч нь өмнөх Intl.NumberFormat("mn-MN") formatter-оор гарна.

SQL/API, дөрвөн картын үндсэн нөхцөл, жагсаалтын шүүлтүүр, дарах үйлдэл өөрчлөгдөөгүй. Дөрөв дэх картыг дарахад төлбөргүй захиалгын жагсаалт нээгдэнэ; доод үлдэгдлийн мэдээлэл нь тусдаа өргөн төлбөрийн үзүүлэлт.

Салбарын нөхцөлтэй summary API outstandingCount болон outstandingBalance-ыг нэг aggregate query-д тооцно. Салбар солих үед шинэ summary иртэл тоонуудын оронд «—» харагдана. Амжилттай 0 утга нь 0 машин, 0₮ болж харагдана; ачаалах/алдааны үед 0 гэж ташаа харагдуулахгүй.

CSS, өнгө, padding, grid, responsive дүрэм өөрчлөгдөөгүй. Stat-ийн тайлбар ReactNode авах боломжтой болсон тул хоёр мөрийг одоогийн small хэсэгт харуулна. Механикийн санхүүгийн мэдээллийг API-аас нуух, amber картыг нуух дүрэм хэвээр.

## Бодит өгөгдлийн зөвхөн унших шалгалт

Gas order Supabase төсөл (`xcnhqcctednqbneseibb`) дээр BEGIN READ ONLY, SELECT, ROLLBACK ашигласан.

Үлдэгдэл = GREATEST(0::bigint, total_price::bigint - advance::bigint - final_paid::bigint).
Үлдэгдэлтэй тоо = COUNT(*) FILTER (WHERE үлдэгдэл > 0).
Нийт үлдэгдэл = COALESCE(SUM(үлдэгдэл), 0).

Одоогийн үндсэн идэвхтэй дөрвөн статус, returned_to_preorder_at IS NULL, салбарын нөхцөл хэвээр; цуцлагдсан хоёр статус хасагдана. Хүлээлгэн өгсөн болон хэсэгчлэн төлсөн захиалгад үлдэгдэл байвал санхүүгийн үзүүлэлтэд орно.

| Салбар | Үлдэгдэлтэй машин | Нийт үлдэгдэл |
| --- | ---: | ---: |
| Бүх салбар | 29 | 146,300,000₮ |
| 16-ын салбар | 29 | 146,300,000₮ |
| Нарны замын салбар | 0 | 0₮ |

3-р салбарт хамрагдах идэвхтэй мөр байгаагүй. Хүлээгдэж буй 29 машины тоо таарсан; зөрүү байхгүй. Энэ нь шалгалтын үеийн snapshot бөгөөд дараагийн захиалга, төлбөрөөс өөрчлөгдөнө.
