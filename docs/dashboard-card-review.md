# Хяналтын самбарын картын өөрчлөлт

Production-д байрлуулаагүй. Хэрэглэгч өөрчлөлтийг шалгаж зөвшөөрсний дараа байрлуулна.

## Үзүүлэлтүүд

| Карт | Өгөгдлийн сангийн нөхцөл |
| --- | --- |
| Программ суулгаагүй | installation_completed IS TRUE AND programming_completed IS NOT TRUE |
| Төхөөрөмж тавиагүй | programming_completed IS TRUE AND installation_completed IS NOT TRUE |
| Аль аль нь хийгдээгүй | programming_completed IS NOT TRUE AND installation_completed IS NOT TRUE |
| Урьдчилгаа төлөөгүй | total_price > 0 AND advance = 0 AND total_price::bigint - advance::bigint - final_paid::bigint > 0 |

Бүх карт үндсэн идэвхтэй төлөвтэй, урьдчилсан захиалга руу буцаагдаагүй захиалгыг сонгоно. Эхний гурав handover_completed IS NOT TRUE нөхцөлтэй. Цуцлагдсан хоёр төлөв хасагдана. Дууссан статус нь дангаараа хүлээлгэн өгсөн гэсэн үг биш; хүлээлгэн өгснийг одоогийн handover_completed талбараар тодорхойлно.

Ажлын boolean талбарууд schema-д NOT NULL DEFAULT false. Хуучин NULL утгыг одоогийн үйл ажиллагааны логиктой адил хийгдээгүй гэж үзнэ.

Хэрэглэгчийн тодруулга: урьдчилгаа заавал төлөхгүй. Дөрөв дэх карт нь идэвхтэй, үнэ > 0, advance = 0, бүрэн төлөөгүй захиалгыг харуулах мэдээллийн үзүүлэлт. advance_type, receipt болон статусыг төлбөрийн баталгаа болгон ашиглахгүй; одоогийн advance дүнг ашиглана. Шинэ төлбөрийн талбар, migration, төлбөр бичих өөрчлөлт оруулаагүй.

## Хэрэглээ

Салбарын сонголт бүх карт болон нээсэн жагсаалтад үйлчилнэ. Картыг дарахад хайлт, үйлчилгээ болон төлбөрийн өмнөх нэмэлт шүүлтүүрүүд арилж, тухайн картын SQL нөхцөлөөр жагсаалт нээгдэнэ. Шүүлтүүрийн нэр, арилгах товч, ачаалах төлөв, алдааны дахин оролдох товч байна.

Картын жагсаалт нь ердийн жагсаалтын 500 мөрийн хязгаарыг ашиглахгүй. Энгийн жагсаалтын хязгаар хэвээр. Өнгө, grid болон responsive CSS хэвээр; картын товч гарын Tab/Enter удирдлагатай. Механикийн санхүүгийн карт нуух өмнөх эрхийн дүрэм хэвээр бөгөөд санхүүгийн жагсаалтын API хүсэлтийг мөн хориглоно.
